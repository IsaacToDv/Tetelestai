# Tetelestai

Party game multijugador low-poly (friendslop) donde cada mapa es un libro de la Biblia. El nombre viene del griego *tetelestai*, «consumado es» (Juan 19:30).

- Diseño: `docs/GDD.md`
- Cómo trabaja el enjambre de Codex: `AGENTS.md`
- Puesta en marcha (local o solo con GitHub): `SETUP.md`
- `Plan.md` y `Sprints.md` los rellena Codex en el Sprint 0, con tu validación.
