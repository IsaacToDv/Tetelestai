# Edén sound effects

These mono clips are original procedural audio made for Tetelestai. The synthesis uses filtered noise and damped oscillators for water, and modulated harmonics for animal calls. Each clip is encoded as Ogg Vorbis and MP3 for browser compatibility.

| Clip | Source |
| --- | --- |
| `river` | Periodic filtered noise and bubbling resonances |
| `splash` | Short filtered noise burst with decaying droplets |
| `drink` | Three wet pulses |
| `sheep` | Voiced harmonics with pitch and amplitude modulation |
| `lion` | Low harmonics and filtered breath |
| `giraffe` | Short, pitched grunt |
